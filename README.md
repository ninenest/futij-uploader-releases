# Futij Uploader downloads

Windows installers for Futij Uploader, the tray companion that uploads gameplay recordings to your Futij server.

## Install or update

Download the `.exe` installer from the [latest release](https://github.com/ninenest/futij-uploader-releases/releases/latest).

For a manual upgrade, quit Futij Uploader from its tray menu and install into the same folder. Your settings are retained. Installing into a different folder leaves the original copy in place.

Versions with the built-in updater check this public repository automatically. You can also choose **Check for updates** in the app, then **Download and install**. The app verifies the installer before opening setup in the current installation folder.

This repository contains downloads and release notes. Application source is maintained separately and is not published here.
